# **📘 Curso de Técnico de Desenvolvimento de Sistemas — Firjan Senai**

- Este repositório reúne todo o conteúdo programático do curso de Desenvolvimento de Sistemas ministrado pela Firjan Senai- Petrópolis/RJ, e desenvolvido por mim durante minha formação.

- Aqui você encontrará atividades, exercícios, projetos, práticas de laboratório e materiais de estudo produzidos ao longo das disciplinas do curso.

## **🎯 Objetivo**

- Documentar o aprendizado adquirido durante o curso.

- Organizar projetos e exercícios realizados em sala.

- Servir como referência futura para estudos e evolução profissional.

- Demonstrar meu progresso na área de desenvolvimento de sistemas.
